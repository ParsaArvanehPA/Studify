Week 11 · Farahzad 2012 Translation Criticism

ترجمهٔ متون مطبوعاتی
Exam Cram5 min read

Author: Dr. Farzaneh Farahzad

Source: Research Journal, Fall 2011

Type: EXAM CRAM - Quick Review

⚡ Exam Focus: This article proposes three-faceted model for translation criticism: Intertextuality + Critical Discourse Analysis + Translation Choices (at textual, paratextual, semiotic levels). Key distinction: Quality Assessment vs. Translation Criticism. Focus on ideological implications of translator choices.

1. Core Distinctions

Quality Assessment vs. Translation Criticism

Quality Assessment (کیفیت‌سنجی) Translation Criticism (نقد ترجمه)
Examines quality Examines function in society
Criteria: correct/incorrect, good/bad, fluent/not fluent Examines ideological positioning
Framework: Equivalence between source and target Framework: Intertextuality + ideology
Used in: translator training, administration, publishing Used in: academic analysis

Two Problems with "Good" Translation

  1. Temporal Change: What's "good" changes over time
    • Example: Haji Baba - good when fluency mattered, questionable now
  2. Fidelity Dilemma: To what/whom be faithful?
    • Faithful to source → literal, not fluent
    • Faithful to reader → fluent, distances from source
    • No clear middle ground

2. Types of Translation Criticism

By Historical Approach

  1. Aesthetic/Taste-based: Subjective, no clear criteria
  2. Linguistic: Closer to evaluation/editing
  3. Social & Historical: Examines text position in target society

By Method

Non-Comparative (غیر مقابله‌ای) Comparative (مقابله‌ای)
Target NOT compared with source Target compared with source OR other translations
Treated as independent text Relationship examined
Example: Arabian Nights Most common type
Focus: theme, narrative form Focus: translation choices & effects
Often historical, used in literary studies Used in translation studies

3. The Three-Faceted Model

⚠️ The Three Facets

  1. Intertextuality (بینامتنیت) - replaces "equivalence"
  2. Critical Discourse Analysis (تحلیل گفتمان انتقادی / CDA) - examines ideology
  3. Translation Choices (انتخاب‌های ترجمه‌ای) at 3 levels:
    • Textual (متنی)
    • Paratextual (پیرامتنی)
    • Semiotic (نشانه‌ای)

4. Facet 1: Intertextuality

Key Concepts

Theorist: Julia Kristeva (French narratologist)

Core Idea: Texts relate to, reference, quote each other

Every Text Has Two Parts:

  1. Referential/Repetitive: Quoted from other texts
  2. Non-referential/New: Created by author

Application to Translation

Replace: "Equivalence" → "Intertextuality"

Why:

  • Target ≠ copy of source
  • Different author, readers, language, society

Target Text Has:

  • Repetitive part from source (concepts, themes, forms)
  • Non-repetitive part due to:
    • Linguistic/cultural/social differences
    • Translator's choices

Example: Khayyam's Rubaiyat

  • Persian original → FitzGerald's English → Secondary translations (German, Russian, French, etc.)
  • All share commonalities BUT differ from each other
  • Relationship = intertextual, NOT equivalence

5. Facet 2: Critical Discourse Analysis (CDA)

Core Assumptions

Fairclough (1995): Language, power, ideology are interconnected

  • Language = vehicle of ideology
  • Text = arena of ideology
  • Word choices → positioning → power centering/marginalizing

Ideology in Translation Studies

Broader than political meaning

Calzada Perez (2003): "Ways of thinking, evaluating, behaving that are promoted in society, become dominant, turn into custom"

6. Facet 3: Translation Choices - Three Levels

Level 1: Textual (سطح متنی)

A. Lexical Choices

Example - Weakening Ideological Load:

  • "stick" (punishment tool) → "حربه" (weapon) - changes nature
  • "awful" (terrifying) → "تعجب برانگیز" (surprising) - removes fear

B. Grammatical Choices

1. Active/Passive:

  • "France put..." → "...was put" - hides agent
  • If repeated → removes agency from source society

2. Nominalization:

  • "Children play role" → "Children's role" - changes from agent to patient

3. Positive/Negative:

  • "stopped" vs. "didn't advance" - different realities

4. Verb Tense:

  • "were excluded" → past perfect vs. present perfect
  • Past = historical; Present = ongoing condition

5. Element Order:

  • First position = more emphasis

C. Translation Strategies

  • Deletion: If patterned → censorship
  • Addition: If repeated → changes representation (e.g., Gone with the Wind - female character)
  • Substitution: محراب → "chapel" - suggests mosque = church

Level 2: Paratextual (سطح پیرامتنی)

Analyzes: Translator/publisher notes, prefaces, afterwords, footnotes

Example 1 - Colonial Footnotes:

  • Western translations of Indian literature
  • Numerous footnotes made India seem exotic/mysterious
  • Paved way for colonialism (per Appiah)

Example 2 - FitzGerald's Preface:

  • "Persian poetry needs little artistic refinement"
  • Reveals Orientalist perspective
  • Devalues Persian/Eastern poetry

Example 3 - Coleman Barks' Rumi:

  • Doesn't know Persian, yet translates Rumi
  • Includes Hindu cooking recipe in afterword
  • Devalues the work

Level 3: Semiotic (سطح نشانه‌ای)

Analyzes: Non-verbal signs - cover images, page layout, font, colors

Example 1 - Gone with the Wind Covers:

  • 1977: Romantic image (Hollywood influence)
  • 1986: War image (Iran-Iraq War context)
  • 2002: Love + war themes
  • Shows: Social conditions + interpretation changes over time

Example 2 - "Why People Hate America" Covers:

  • English: Burning American flag (hatred)
  • Persian: American military presence (NOT hatred)
  • Difference = ideological difference

7. Model Methodology

Process

  1. Analyze translation choices
  2. Explain ideologically with attention to social/political/historical context
  3. Conduct at all three levels: textual, paratextual, semiotic

Type: Comparative criticism

Focus: What translation DOES (not what it IS)

8. Exam Checklist

✓ Must Know for Exam

  • ☑ Quality Assessment ≠ Translation Criticism
  • ☑ "Good" translation concept changes over time (Haji Baba example)
  • ☑ Fidelity dilemma: to source (literal) vs. to reader (fluent)
  • ☑ Two types by method: Non-comparative vs. Comparative
  • ☑ THREE FACETS: Intertextuality + CDA + Translation Choices
  • ☑ Intertextuality (Kristeva): Every text has referential + non-referential parts
  • ☑ Replace "equivalence" with "intertextuality"
  • ☑ CDA (Fairclough): Language-power-ideology interconnected
  • ☑ THREE LEVELS of analysis: Textual + Paratextual + Semiotic
  • ☑ Textual level: Lexical (stick→حربه), Grammatical (active→passive), Strategies (deletion/addition)
  • ☑ Paratextual level: Footnotes, prefaces (FitzGerald, Barks examples)
  • ☑ Semiotic level: Cover images (Gone with the Wind, Why People Hate America)
  • ☑ Focus shift: "What IS translation" → "What DOES translation do"
  • ☑ All translator choices have ideological implications

9. Key Examples to Remember

For Each Level

Textual:

  • محراب → "chapel" (cultural substitution)
  • Active → Passive (agent deletion)

Paratextual:

  • FitzGerald: "Persian poetry needs little refinement"
  • Barks: Cooking recipe with Rumi translation
  • Colonial footnotes on Indian literature

Semiotic:

  • Gone with the Wind 3 covers (1977, 1986, 2002)
  • Why People Hate America: Burning flag vs. Military presence

🎯 Central Argument

Main Shift: From "what is translation" to "what does translation DO"

Key Insight: Translator choices (words, grammar, strategies, paratexts, visual elements) reveal ideological positioning

Model Application: Examine translations for position and ideological effects in target society at three levels

Foundation: Intertextuality (replaces equivalence) + CDA (reveals power-ideology connections) + Three-level analysis (comprehensive coverage)
