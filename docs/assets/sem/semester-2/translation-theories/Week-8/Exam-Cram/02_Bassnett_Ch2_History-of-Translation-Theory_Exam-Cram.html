⚡ History of Translation Theory · EXAM CRAM

Susan Bassnett, Ch. 2 | Just the essentials

🎯 Recurring Line

Word-for-word vs. sense-for-sense keeps reappearing across history. Culture is dynamic (Lotman) — no rigid periods.

📌 Steiner's Four Periods

(1) Cicero → Tytler 1791 (empirical). (2) → Larbaud 1946 (hermeneutic). (3) 1940s+ (machine translation, linguistics). (4) 1960s+ (hermeneutic return).

📌 Key Figures Chain

Romans: Cicero + Horace — translation as enrichment (not copying). Dolet (1540): Five principles — executed. Dryden (1680): Metaphrase / paraphrase / imitation. Goethe: 3 epochs of translation. Tytler (1791): First systematic English study.

📌 Victorians — The Archaizing Debate

Arnold: Translate for the "competent scholar." Newman: Deliberate foreignness. Longfellow: Extreme literal — "report, don't explain." Fitzgerald: "Live sparrow than stuffed eagle."
Archaizing paradox: respect for original → restricted to minority → devaluation of translation.

📌 5 Late-19th c. Translation Types

Scholarship / Return to ST / Deliberate foreignness / Pragmatic choice / Upgrading ST

📌 Late 20th Century

Cultural turn (Lefevere & Bassnett 1990): translation is never innocent — power relations matter. Skopos theory: breaks the faithful/free axis (Gentzler).

📌 Internet Age

Pym's paradox: info proliferation ≠ more reading. AVT should be an autonomous field — old debates irrelevant.
