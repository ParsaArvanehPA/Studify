⚡ Specific Problems of Literary Translation · EXAM CRAM

Susan Bassnett, Ch. 3 | Just the essentials

🎯 Core

A literary text = complex set of interrelated systems. Focus on ONE element = failure. Every reading = interpretation. No single "right way."

📌 Lefevere's 7 Poetry Strategies (EXAM GOLD)

1. Phonemic / 2. Literal / 3. Metrical / 4. Poetry into prose / 5. Rhymed / 6. Blank verse / 7. Interpretation (versions + imitations)
Each FAILS by overemphasizing one element. The poem = an ORGANIC STRUCTURE. Popovic: "right to differ organically... for the sake of the original."

📌 Catullus Paradox

Closer in FORM (Marris forced rhyme) = FURTHER in function. Huge deviations (Ben Jonson) = NEARER in mood/tone. Form ≠ function correlation.

📌 Pound vs. Kennedy (The Seafarer)

Pound: removed Christian references, mock-Anglo-Saxon, individual suffering. Kennedy: half-lines preserved, contemporary language. Both = starting points for new poems.

📌 Prose Translation

Belloc's 6 rules: (1) Block out / (2) Idiom by idiom / (3) Intention by intention / (4) Beware false friends / (5) Transmute boldly / (6) Never embellish
The Mann and Silone examples show translators often miss structural patterns by NOT reading the whole text first.

📌 Dramatic Translation

Text is INCOMPLETE — realized only in performance. Must consider: playability, gestural patterns, stage conventions. The Racine translations show very different approaches (Cairncross formal; Lowell colloquial; Harrison radical relocation to colonial India).
