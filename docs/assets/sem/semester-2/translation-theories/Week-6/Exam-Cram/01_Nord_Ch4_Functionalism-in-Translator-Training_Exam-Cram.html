🎯 The Practical Chapter

How to actually DO functionalist translation. Complete toolkit: functions, typologies, the brief, problem types, top-down process, error types, vertical units.

📌 Four Text Functions

Referential (world objects/events) — Expressive (sender's attitude) — Appellative (direct receiver) — Phatic (maintain contact)

📌 Documentary vs. Instrumental (EXAM GOLD)

Documentary: "a text about a text" — interlinear / literal / philological / exoticizing. Instrumental: readers don't notice it's a translation — equifunctional / heterofunctional / homologous.

📌 The Translation Brief

Contains: function + addressee + time/place + medium + motive. Specifies WHAT not HOW.

📌 4 Translation Problem Types

Pragmatic (most important, present in every task) → Cultural (norms/conventions) → Linguistic (language structure differences) → Text-specific (unique to one ST)

📌 Top-Down vs. Bottom-Up

Bottom-up: words → conventions → pragmatics. Leads to interference. Top-down: pragmatics → conventions → language. Produces REASONED decisions.

📌 4 Error Types (Matching Problems)

Pragmatic (most serious — receiver gets wrong info unknowingly) / Cultural (inadequate convention handling) / Linguistic (competence deficits) / Text-specific (unique problems)

📌 Vertical Translation Units

Functional units at ANY linguistic rank serving ONE communicative function. Solves untranslatability: render the function, not the form.
